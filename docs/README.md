## Starter provenance

The supplied starter was incomplete: three complete file blocks and the text of AGENTS.md
without its closing marker were available. `.editorconfig` and the pull request template
were recovered verbatim; AGENTS.md contains the supplied text through work-sequence step 8.
The remaining documents and discovery prompt were drafted for this project on 2026-11-16.
They are replacements, not a reconstruction of the missing original files.
The existing root README and `.gitignore` were preserved. The final approved stack is Python/FastAPI/Uvicorn with HTML, CSS, JavaScript and Leaflet.

The user authorised project setup after discovery. This foundation does not publish the
cloud environment, deploy an application, or establish acoustic validity.
