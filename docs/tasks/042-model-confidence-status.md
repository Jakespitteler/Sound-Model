# 042 — Make the model and confidence visible

The map toolbar shows current calculation activity and source evidence. Open **Model
details** to see which sources rely on example power, user-entered measurements or a
field fit. If the fitted machine is moved, copied, or edited in a way that changes
its fitted setup, the panel identifies the earlier checks as historical.

The panel describes distance spreading, sound-energy addition, the point-source area
approximation and the scenario-wide background rule. It calls out terrain and weather
omissions, near-source limits, simultaneous operation and double counting. Receiver
details show the nearest active source distance when available and identify the result
as an open-space prediction. Receiver details flag positions inside fitted areas and beyond
held-back check distances. Field checks describe the tested conditions and locations.

area and truck scenario, its current background and its evidence summary. Desktop and
390 px screenshots were inspected using synthetic readings and the fallback map.
